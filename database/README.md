# 数据库

一期首选 SQLite，后续按需求评估 PostgreSQL。当前只建立管理目录，未创建数据表、迁移脚本或数据库文件。

| 目录 | 内容 |
|---|---|
| `schema/` | 数据模型、关系图、字段字典与约束 |
| `migrations/sqlite/` | 验证迁移工具后添加的 SQLite 版本化迁移 |
| `seeds/` | 明确标记的开发演示数据，不使用真实用户数据 |

模型以 Plan、Recurrence、Task、Work Log 为核心；详见原始产品规划。建模时必须明确周期实例唯一键、任务来源、日期/时间戳语义、进度变更历史和目标汇总口径。

迁移工具拟采用 Flyway，需先验证 SQLite 支持与分发方案，再提交首个 `V1__*.sql`。已应用的迁移不修改，后续通过新迁移演进。迁移文件在本目录唯一维护，由后端构建打包。

数据库文件、WAL、备份与日志只存放在仓库外或被忽略的 `.runtime/` 下。备份采用 SQLite 一致性备份方式并演练恢复，不在运行时仅复制单一数据库文件。
