# MVP 实施与验收

业务定义见 [产品规划](./product.md)，技术方案见 [技术文档](./technical.md)。以下实施与验收均待完成。

## 实施顺序

1. 初始化 Web 与 Spring Boot，锁定依赖并验证 SQLite、迁移工具和 API 契约来源。
2. 完成四模块原型、数据模型与接口定义。
3. 实现计划、任务、工作记录，再接入工作台与周期任务生成。
4. 验证内网部署、数据迁移与备份恢复。

一期不要求桌面端、完整甘特图、自动化执行、多用户或 AI Agent。

## 实现前需确认

- 工作时区与日期存储方式、月末缺失日期的处理。
- 周期实例预生成窗口（产品规划建议 14 天）。
- 目标进度模式、完成确认、本周完成率统计口径。
- 规则变更与未来已手动改期实例的冲突处理。
- 服务器 JDK、Nginx、原生驱动能力及访问控制、备份位置。

## 验收清单

### 核心场景

- [ ] 创建每周一例会，可预览未来发生日，本周/下周有独立任务实例。
- [ ] 多次生成同一周期实例无重复；重启补偿也保持幂等。
- [ ] 单次取消/改期不改变后续实例；规则调整保留已执行历史与例外。
- [ ] 目标拆解为子任务，目标汇总与子任务不重复计数。
- [ ] 连续记录目标进展，进度与卡点历史可追溯。
- [ ] 快速新增临时任务，无需先建计划；支持独立补录工作记录。

### 规则与视图

- [ ] 工作台、任务中心及周日历展示同一任务源。
- [ ] 逾期由截止日期与状态派生；已完成/已取消不标逾期。
- [ ] 进度 100% 与完成状态按已明确规则处理。
- [ ] 任务状态、来源、优先级可独立筛选与更新。
- [ ] 日期、月末缺失日期、跨日/跨周、时区与统计分母均符合已记录规则。
- [ ] 任务改名后工作记录仍保留必要上下文。

### 交付与运行

- [ ] 真实 Web / 后端构建、类型检查和相关业务测试通过。
- [ ] 迁移可从空库执行并验证升级路径；失败处理方式明确。
- [ ] 数据库驱动可在目标服务器加载，文件目录权限满足部署要求。
- [ ] 静态资源和 `/api` 反代可用；访问控制与配置边界已验证。
- [ ] 一致性备份及恢复演练完成；仓库没有真实数据或密钥。
