# MVP 里程碑

M0 已建立仓库骨架，完成条件包括结构检查与推送；M1–M5 尚未实施，不预设交付日期。

| 阶段 | 工作 | 退出条件 |
|---|---|---|
| M0 仓库基础 | 目录、协作规则、文档、结构 CI | 结构检查通过且仓库已推送 |
| M1 可运行骨架 | 锁定环境与依赖、初始化 Web / Spring Boot、验证 SQLite 与迁移、确定 API 契约来源 | 两端能启动、数据库迁移可重复验证、真实构建与测试接入 CI |
| M2 原型与模型 | 四模块原型、字段/状态/统计规则、数据模型与接口 | 关键流程可演示，待决策项已明确 |
| M3 核心闭环 | 计划、统一任务中心、关联/独立工作记录 | 三个核心场景通过，历史数据可追溯 |
| M4 工作台与周期 | 日历、汇总、风险、幂等生成与启动补偿 | 日期边界、重复执行、规则变更验证通过 |
| M5 内网交付 | Nginx、JAR、静态构建产物、迁移、备份恢复 | 目标服务器部署、恢复演练及 MVP 验收通过 |

阶段二再初始化桌面工程与系统能力；现阶段不安装桌面运行依赖。
