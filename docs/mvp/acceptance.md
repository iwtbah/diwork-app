# MVP 验收清单

以下均为待执行验证，结构初始化不代表这些项目通过。

## 核心场景

- [ ] 创建每周一例会，可预览未来发生日，本周/下周有独立任务实例。
- [ ] 多次生成同一周期实例无重复；重启补偿也保持幂等。
- [ ] 单次取消/改期不改变后续实例；规则调整保留已执行历史与例外。
- [ ] 目标拆解为子任务，目标汇总与子任务不重复计数。
- [ ] 连续记录目标进展，进度与卡点历史可追溯。
- [ ] 快速新增临时任务，无需先建计划；支持独立补录工作记录。

## 规则与视图

- [ ] 工作台、任务中心及周日历展示同一任务源。
- [ ] 逾期由截止日期与状态派生；已完成/已取消不标逾期。
- [ ] 进度 100% 与完成状态按已明确规则处理。
- [ ] 任务状态、来源、优先级可独立筛选与更新。
- [ ] 日期、月末缺失日期、跨日/跨周、时区与统计分母均符合已记录规则。
- [ ] 任务改名后工作记录仍保留必要上下文。

## 交付与运行

- [ ] 真实 Web / 后端构建、类型检查和相关业务测试通过。
- [ ] 迁移可从空库执行并验证升级路径；失败处理方式明确。
- [ ] 数据库驱动可在目标服务器加载，文件目录权限满足部署要求。
- [ ] 静态资源和 `/api` 反代可用；访问控制与配置边界已验证。
- [ ] 一致性备份及恢复演练完成；仓库没有真实数据或密钥。
