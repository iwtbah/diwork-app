# MVP 交付范围

来源：[产品规划 V1.1](../../个人工作管理平台_产品功能规划_V1.1.md)。本文件是实施索引，不替代完整业务规则。

## 一期

| 模块 | 验收范围 |
|---|---|
| 工作台 | 今日任务、本周日历、汇总与逾期提醒 |
| 工作计划 | 日/周/月周期、一次性计划、目标计划及生成预览 |
| 任务中心 | 周期/目标/临时三来源统一，状态、优先级与筛选 |
| 工作记录 | 关联任务或独立记录，内容、成果、卡点及进度历史 |
| 基础交付 | Web、后端、数据库迁移、备份恢复、内网部署验证 |

## 后续阶段

Tauri 桌面外壳、完整甘特图、自动化执行、能力市场、团队协作及 AI Agent 不属于一期验收条件。当前为这些方向保留目录与职责边界。

## 实现前需明确

- 工作时区默认值、时间戳/日期存储方式。
- 月末不存在日期的产品选项，未来实例窗口（原文建议 14 天）。
- 目标进度模式、任务完成确认与本周完成率统计口径。
- 未来已手动改期实例遇规则变更时的冲突处理。
- 内网访问控制、服务器 JDK / Nginx 能力、驱动原生库加载与备份存储位置。

这些决策需记录后再实现，不能静默选择与产品规则冲突的默认行为。
