# 项目 AI Skills

此目录用于项目专用、可复用的 AI 开发工作流；当前没有已安装的项目技能，也不是产品内 AI Agent 的实现目录。

```text
.agents/skills/
└── <skill-name>/
    ├── SKILL.md       # 触发条件、输入、步骤、验证与边界
    ├── references/    # 可选参考材料
    └── scripts/       # 可选辅助脚本
```

新增技能时：

- 使用小写英文连字符命名，`SKILL.md` 包含 `name`、`description` 元信息与明确适用场景。
- 优先引用仓库规范，不复制长期可能分叉的业务规则。
- 说明输入、执行步骤、输出与验证方式；脚本先验证再复用。
- 不包含密钥、私人数据或覆盖用户授权边界的指令。
- 技能仅在匹配任务时加载，不意味着可以自动发布、删除或访问外部账号。

可按实际重复工作沉淀原型实现、API 契约同步、数据库迁移检查等技能，避免预先添加未验证的流程。
